# My Pixel Buds for Desktop
Don't want to use Google Chrome but still want your Pixel Buds? Use the open-source desktop app! It is an unofficial app built with **Tauri** and **Rust**. The app is built for Windows, and has only been tested on Windows 11.
# Features
- Native Web Bluetooth Support
- Chrome User-Agent Emulation
- Frameless Window Integration
- Smart Auth Redirect
